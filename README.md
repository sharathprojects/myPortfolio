# Sharath Kumar H — Portfolio

Responsive personal portfolio built with HTML and CSS.

## Files

- `index.html` — portfolio page
- `style.css` — responsive styling
- `resume.pdf` — add your final resume PDF here

## Before publishing

1. Replace the LinkedIn URL in `index.html`.
2. Replace the GitHub URL in `index.html`.
3. Add your final resume as `resume.pdf` in this folder.
4. If you have a live portfolio URL, replace the relevant placeholder links.

## Run locally

Open the folder in VS Code and open `index.html` in a browser.

For the best development experience, use the VS Code Live Server extension.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `sharath-portfolio`.
2. Upload `index.html` and `style.css`.
3. Commit and push the files.
4. Open repository Settings → Pages.
5. Under Build and deployment, select:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
6. Save.
7. GitHub will provide your Pages URL.

Your portfolio will then be available at a URL similar to:

`https://YOUR-USERNAME.github.io/sharath-portfolio/`
